# Documentation - Mixed Media Utility

Ce dossier contient la documentation utilisateur et développeur pour le projet Mixed Media Utility.

Fichiers principaux :
- `USAGE.md` — guide d'utilisation et menu d'aide.
- `DEPLOYMENT.md` — instructions de packaging et déploiement (macOS recommandé).
- `ARCHITECTURE.md` — architecture technique et choix de stack.
- `HELP_MENU.md` — texte à intégrer dans le menu d'aide de l'application.

- `test-chaine-extract-makepdf.md` — test manuel extract → makepdf (Epics 3/4).
- `test-chaine-scan-epic5.md` — test manuel de la commande `scan` (Epic 5) :
  de la planche imprimée au manifest mis à jour.
